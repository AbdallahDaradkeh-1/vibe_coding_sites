# تقرير اختبار – مخابز الأحلام

**نطاق الاختبار:** النسخة الأولية للموقع ولوحة الإدارة باستخدام قاعدة بيانات SQLite تجريبية معزولة عن بيانات المشروع النهائية.

## حدود الاختبار

1. اختبارات العرض المرئي في Chromium استُخدمت فيها استجابات API تجريبية مع بيانات المتجر؛ أما اختبارات قاعدة البيانات والواجهات البرمجية فتمت على خادم محلي وقاعدة SQLite مستقلة.
2. لم يتم التحقق من ظهور Google Maps من شبكة إنترنت فعلية في بيئة الاختبار. كما أن دبوس الفرع الدقيق لا يمكن تثبيته قبل الحصول على إحداثيات أو رابط موقع مؤكد.
3. لم يتم اختبار استقبال الطلبات من موظفي المخبز على أرض الواقع أو إرسال إشعارات SMS/WhatsApp/البريد؛ هذه الخدمات غير مفعّلة في النسخة الحالية.
4. الصور الموجودة رسومات SVG مؤقتة وليست صور المنتجات الحقيقية.
5. لم يتم نشر التطبيق على استضافة عامة أو إجراء اختبار أمني خارجي.

## قرار الجاهزية

النسخة جاهزة للتجربة المحلية ومراجعة التصميم والوظائف الأساسية. قبل النشر العام، يجب استكمال معلومات المخبز الحقيقية، وتأكيد الموقع الدقيق والأسعار ورسوم التوصيل وساعات العمل، ثم تنفيذ إعدادات الاستضافة الآمنة والاختبارات التشغيلية النهائية.
