# مخابز الأحلام – Dream Bakeries

موقع عربي متجاوب لمخبز يضم المخبوزات والمعجنات والحلويات ومطعماً داخلياً. يتضمن الموقع واجهة للزوار، سلة طلبات، إرسال طلب توصيل أو استلام، ولوحة إدارة للمنتجات والأقسام والطلبات.

## التقنيات

- Python 3.10 أو أحدث.
- مكتبات Python القياسية فقط (لا حاجة إلى `pip install`).
- SQLite لتخزين المنتجات والأقسام وحساب المدير والطلبات.
- HTML وCSS وJavaScript بدون إطار عمل Front-End.

> يتطلب تشغيل المشروع محلياً Python 3.10+؛ ويُفضّل Python 3.11 أو 3.12 أو 3.13. تستخدم قاعدة البيانات SQLite المدمجة في Python.

## التشغيل محلياً

1. فك ضغط مجلد المشروع وافتح Terminal داخله.
2. أنشئ حساب المدير لأول مرة (على Windows يمكن تشغيل `create_admin_windows.bat`، أو تنفيذ الأمر التالي):

   ```bash
   python app.py --create-admin
   ```

   أدخل اسم المستخدم وكلمة مرور قوية من 12 خانة على الأقل. لا يوجد حساب مدير أو كلمة مرور افتراضية مضمنة في المشروع.

3. شغّل الموقع (على Windows يمكن تشغيل `run_windows.bat`، أو تنفيذ الأمر التالي):

   ```bash
   python app.py
   ```

4. افتح:
   - واجهة العملاء: `http://127.0.0.1:8000`
   - لوحة الإدارة: `http://127.0.0.1:8000/admin`

لإيقاف الخادم اضغط `Ctrl + C`.

### إعداد اختياري عبر متغيرات البيئة

يمكن إنشاء أول حساب مدير عند أول تشغيل من خلال تعيين `ADMIN_USERNAME` و`ADMIN_PASSWORD` في بيئة التشغيل. يجب أن تكون كلمة المرور 12 خانة على الأقل. لا تضع كلمة المرور الحقيقية في ملف عام أو في مستودع Git.

يمكن أيضاً تغيير المضيف والمنفذ عبر `HOST` و`PORT`. عند النشر خلف HTTPS، اضبط `COOKIE_SECURE=1`.

## ما الذي يعمل في النسخة الحالية؟

### واجهة العملاء

- صفحة رئيسية عربية باتجاه RTL ومتجاوبة.
- أقسام: المخبوزات، المعجنات، الحلويات، المطعم.
- المنتجات الأولية مأخوذة من قائمة المشروع.
- تصفية المنتجات حسب القسم.
- سلة مع زيادة الكمية وتقليلها وحذف المنتج.
- نموذج طلب مع اختيار التوصيل أو الاستلام.
- التحقق من البيانات وتخزين الطلب في SQLite.
- رقم مرجعي للطلب بعد استلامه من النظام.
- الهاتف والعنوان وروابط الاتصال والخريطة.

### لوحة الإدارة

- تسجيل دخول محمي بحساب مدير يُنشأ محلياً.
- إحصاءات مختصرة.
- إضافة المنتجات وتعديلها وحذفها.
- تعديل السعر أو تركه فارغاً إلى أن يزوّدنا المخبز بالسعر الصحيح.
- رفع صورة خاصة للمنتج بصيغ JPG أو PNG أو WebP (بحد أقصى 2 ميغابايت).
- إظهار المنتج أو إخفاؤه من قائمة العملاء.
- تحديد المنتج المميز.
- إضافة الأقسام وحذف القسم الفارغ.
- مشاهدة الطلبات وتغيير حالتها.

## البيانات الافتراضية والحدود الحالية

- أسماء المنتجات والأقسام مبدئية اعتماداً على المتطلبات التي تم تزويدنا بها.
- الأسعار غير مدخلة؛ يظهر للزائر «السعر عند الطلب» إلى أن تُضاف الأسعار الحقيقية من لوحة الإدارة.
- رسومات SVG الموجودة في `public/images` هي رسومات توضيحية محلية مؤقتة وليست صوراً حقيقية لمنتجات المخبز.
- خريطة Google تعرض منطقة أبو نصير – حي الأمانة بشكل تقريبي. لا توجد إحداثيات GPS دقيقة مؤكدة للفرع بعد، لذلك لم يتم وضع علامة تدّعي تحديد موقع المخبز بالضبط.
- لا توجد بوابة دفع إلكتروني.
- رسوم التوصيل والمناطق المتاحة غير محددة، وتحتاج إلى تأكيد من الإدارة.
- الطلبات تُحفظ في قاعدة البيانات وتظهر داخل لوحة الإدارة. النسخة الحالية لا ترسل SMS أو بريداً أو إشعار WhatsApp تلقائياً.
- لا توجد ساعات عمل أو حسابات تواصل اجتماعي لأن هذه المعلومات لم تُزوّد بعد.

## الملفات المهمة

```text
app.py                    خادم Python وواجهات API وقاعدة البيانات
public/index.html         الصفحة الرئيسية
public/styles.css         تصميم واجهة العملاء
public/app.js             سلة الطلبات وإرسال الطلبات
public/admin.html         واجهة لوحة الإدارة
public/admin.css          تصميم لوحة الإدارة
public/admin.js           وظائف لوحة الإدارة
public/images/            الشعار والرسومات التوضيحية
 data/                    قاعدة SQLite (تنشأ تلقائياً عند التشغيل)
```

## قاعدة البيانات

تنشأ قاعدة البيانات تلقائياً في `data/dream_bakeries.sqlite3` عند أول تشغيل. تشمل الجداول الأساسية:

- `categories`
- `products`
- `admin_users`
- `orders`
- `order_items`

تحتوي القاعدة على الأقسام والمنتجات الأولية. لا تُحذف قاعدة البيانات عند إعادة تشغيل التطبيق.

## تحديث بيانات التواصل والموقع

رقم الهاتف والعنوان الحاليان محددان في `app.py` ضمن مسار `/api/store`، كما يظهران في الواجهة الثابتة. عند تأكيد الإحداثيات الدقيقة، حدّث مصدر iframe ورابط Google Maps داخل `public/index.html` حتى يشيرا إلى دبوس الفرع الصحيح.

## ملاحظات قبل النشر التجاري

هذه نسخة تشغيلية أولية (MVP) قابلة للتجربة محلياً، وليست تهيئة نشر إنتاجي نهائية. قبل إتاحتها للجمهور، ينبغي:

1. استضافة التطبيق خلف HTTPS مع `COOKIE_SECURE=1` واستخدام خادم تطبيق مناسب ونسخ احتياطية منتظمة لقاعدة البيانات.
2. مراجعة سياسة الخصوصية وشروط الطلبات، وتحديد من يطلع على بيانات العملاء.
3. إضافة حماية أقوى من محاولات تسجيل الدخول المتكررة، ومراجعة إعدادات الخادم والجدار الناري.
4. تأكيد الأسعار، ساعات العمل، رسوم ومناطق التوصيل، رقم التواصل بصيغته الدولية عند الحاجة، وموقع الفرع الدقيق.
5. استبدال الرسومات التوضيحية بصور حقيقية يملك المخبز حق استخدامها.
6. اختبار استقبال الطلبات مع موظف المخبز فعلياً وتحديد طريقة متابعة الطلبات والتواصل مع العميل.

لا تعتبر حالة الطلب «مؤكدة» لمجرد إرساله من الواجهة؛ الطلب الجديد يظهر في لوحة الإدارة بحالة «جديد»، ويحتاج إلى مراجعة من الموظف.
